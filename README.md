# Ecommerce Admin Panel

Modern ecommerce admin dashboard built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, React Hook Form, Zod, Axios, Recharts, and TanStack Table.

## Features

- JWT authentication with protected routes
- Dashboard analytics, charts, and widgets
- Users, categories, products, cart, wishlist, orders modules
- Dark mode toggle
- Responsive sidebar and mobile navigation
- Reusable UI components, skeletons, and modals

## Setup

1. Install dependencies

   ```bash
   npm install
   ```

2. Start development server

   ```bash
   npm run dev
   ```

## API Base URL

- `http://127.0.0.1:8000`

> Replace backend endpoints with your FastAPI backend if needed.
